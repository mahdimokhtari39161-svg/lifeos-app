# قاسمی — ابزار مهر و امضا روی نقشه

نسخه مستقل و نصب‌پذیر ابزار مهر و امضا.

## امکانات

- بارگذاری یک یا چند تصویر نقشه
- تعریف مهر و امضای PNG با پس‌زمینه شفاف
- جابه‌جایی با لمس/ماوس و تغییر اندازه و چرخش با دو انگشت
- حالت ساده و پیشرفته، پروفایل‌های جداگانه و تنظیم جایگاه پیش‌فرض
- خروجی تصویر JPG یا PNG و خروجی PDF چندصفحه‌ای
- نصب به‌صورت PWA از مرورگر و ساخت APK اندروید با GitHub Actions

## اجرای نسخه وب

آدرس برنامه پس از انتشار GitHub Pages:

https://mahdimokhtari39161-svg.github.io/lifeos-app/stamp-tool/

در Chrome اندروید صفحه را باز کنید و از منوی مرورگر گزینه **Install app** یا **Add to Home screen** را بزنید.

## ساخت APK

پس از push شدن تغییرات در پوشه stamp-tool/، به تب **Actions** مخزن lifeos-app بروید و اجرای **Build Stamp Tool Android APK** را باز کنید. فایل app-debug.apk در بخش **Artifacts** با نام **Qassemi-Stamp-Tool-APK** قرار می‌گیرد. APK را دانلود، از حالت فشرده خارج و روی اندروید نصب کنید.

## حریم خصوصی و نگهداری داده

پردازش تصویر در مرورگر انجام می‌شود و این نسخه فایل نقشه را به سرور ارسال نمی‌کند. اطلاعات مهر، امضا و پروفایل در حافظه محلی مرورگر ذخیره می‌شوند؛ تصویرهای نقشه پس از تازه‌سازی صفحه باید دوباره بارگذاری شوند. پاک‌کردن داده‌های مرورگر می‌تواند پروفایل‌های ذخیره‌شده را حذف کند.

## نکته

برای خروجی تمیز، فایل مهر و امضا را به‌صورت PNG با پس‌زمینه شفاف آماده کنید.
