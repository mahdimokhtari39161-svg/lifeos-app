# آخرین پناهگاه — Last Shelter

A Persian, mobile-first survival arena game built with HTML Canvas and vanilla JavaScript.

## Play
After GitHub Pages is enabled for the parent repository, open:

https://mahdimokhtari39161-svg.github.io/lifeos-app/survival-game/

On Android Chrome, use **Install app** / **Add to Home screen**. The game is a PWA and caches its app shell for offline opening after the first successful load.

## Gameplay
- Touch joystick movement and automatic targeting/shooting
- Endless escalating enemy waves
- Collect scrap and medical supplies
- Upgrade weapon damage, fire rate, movement speed, and armor
- Save progress locally on the device
- Responsive portrait layout

## Notes
This is a playable prototype, not a finished commercial online game. Progress is stored locally; there is no multiplayer, cloud account, or server-side leaderboard yet.
